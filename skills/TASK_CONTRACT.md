# Skill: Task Contract

Use this contract for every substantive task or batch item.

```text
ID:
Objective:
Scope/files:
Dependencies:
Owner/agent:
Write set:
Risk:
Acceptance criteria:
Verification:
Status:
Evidence:
Next action/blocker:
```

A task may move to `DONE` only after its acceptance criteria are satisfied and evidence is recorded. Use `UNKNOWN` when evidence is unavailable and `BLOCKED` when work cannot safely continue.
