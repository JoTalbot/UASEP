# Skill: Handoff

Before ending a work session, update `.uasep/state/HANDOFF.md`.

Required fields:

- current objective;
- exact step reached;
- completed tasks and commit IDs;
- unverified changes;
- active blockers;
- files currently being changed;
- decisions that must not be lost;
- recommended next action.

Write for an agent that has no access to the previous chat. A handoff must be sufficient to continue safely without asking what happened earlier.
