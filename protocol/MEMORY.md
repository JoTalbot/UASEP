# Project Memory Protocol

Durable project memory belongs in the repository when persistent external memory is unavailable or insufficient.

## Memory classes

- current state
- active work
- decisions
- solved problems
- failed approaches
- architectural knowledge
- reusable patterns
- evidence
- handoff

## Rules

Record concise, durable facts rather than chat transcripts. Prefer links to files, tasks, commits, tests, and evidence. Mark uncertainty explicitly. Remove obsolete state through controlled updates rather than silently rewriting history.

A new agent should be able to reconstruct enough context to continue safely without the previous conversation.
