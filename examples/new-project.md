# Example: New Project

1. Run the short UASEP bootstrap.
2. Discover environment and capabilities.
3. Detect that no project state exists.
4. Initialize `.uasep/` using the protocol source of truth.
5. Inspect the requested product goal and convert it into requirements and a task graph.
6. Implement the highest-value ready task.
7. Verify with available tests/checks.
8. Persist evidence and state.
9. Continue until the current objective is complete.
10. Enter maintenance and improvement mode after completion.

The agent must not report completion solely because scaffolding was created.
