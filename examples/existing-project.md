# Example: Existing Project

1. Run the same short bootstrap.
2. Discover capabilities and repository state.
3. Load `.uasep/` if present.
4. Inspect current code, tests, CI, documentation, and recent evidence.
5. Detect incomplete work, regressions, blockers, and architecture drift.
6. Rebuild the task graph from factual state.
7. Implement and verify the next highest-value task.
8. Persist state and evidence.
9. Repeat without requiring the previous chat history.
