# New Project Example

Use this pattern when UASEP is introduced before substantive project work begins.

## Initial repository

Create the project-local agent contract and UASEP durable structure before the first consequential task.

## Bootstrap state

Record:

- project objective;
- active branch;
- constraints and non-goals;
- available connected capabilities;
- baseline verification status;
- first task and acceptance criteria.

## First task

The first task must have an explicit owner, write set, dependencies, risk, and verification plan. A new agent must be able to reconstruct the state from repository files alone.

## Normal operation

Follow the canonical task lifecycle and use the parallel-batch rules whenever multiple tasks are considered together. Keep implementation evidence separate from verification evidence.

## Completion

Before handing off, update durable state and identify the exact next action. Do not rely on the originating chat as the project record.
