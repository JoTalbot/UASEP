# Task Record

## ID

`UASEP-...`

## Objective

What outcome must exist when the task is done?

## Scope / files

List exact files or areas that may change.

## Dependencies

Tasks, decisions, capabilities, or information that must exist first.

## Owner / agent

Who currently owns the task.

## Write set

Exact files the task may modify.

## Risk

What could break or become difficult to recover?

## Acceptance criteria

Observable conditions required for completion.

## Verification

Specific checks that will prove the criteria.

## Status

`PLANNED | IN_PROGRESS | VERIFIED | PARTIALLY_VERIFIED | UNKNOWN | FAILED | BLOCKED | DONE`

## Evidence

Commit IDs, test/CI results, review notes, or repository observations.

## Next action / blocker

Exact continuation step.
