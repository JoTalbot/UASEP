# C64.2 Governance, Compliance & Policy Framework

## Purpose
Define auditable structures for governance rules, compliance controls, policies, evidence and approvals.

## Records
- policy identity/version
- control objectives
- requirements
- evidence sources
- risk classification
- exceptions
- ownership
- approval state
- review history

## Lifecycle
`DEFINED -> ASSESSED -> REVIEWED -> APPROVED -> ACTIVE -> MONITORED -> UPDATED`

## Rules
Governance requires explicit ownership, evidence, reviewability and traceable decisions. High-impact exceptions require escalation.
