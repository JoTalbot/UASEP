# C65.2 Resource Capability Infrastructure Framework

## Purpose
Define auditable structures for representing infrastructure resources, capabilities, constraints and lifecycle operations.

## Components
- resource registry
- capability registry
- dependency graph
- capacity models
- ownership and authority records
- lifecycle states
- health indicators
- allocation policies

## Lifecycle
`DISCOVERED -> REGISTERED -> ASSESSED -> ALLOCATED -> MONITORED -> OPTIMIZED -> RETIRED`

## Rules
Resources require explicit ownership, scope, provenance and governance controls before material changes.
