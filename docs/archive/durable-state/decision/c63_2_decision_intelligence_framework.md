# C63.2 Decision Intelligence Framework

## Purpose
Define auditable structures for representing decisions, alternatives, constraints and approvals.

## Decision Record
- identifier/version
- context and objective
- alternatives
- evidence
- risks
- assumptions
- constraints
- authority scope
- rationale
- approval state
- outcome feedback

## Lifecycle
`REQUESTED -> ANALYZED -> REVIEWED -> APPROVED -> EXECUTED -> VERIFIED -> LEARNED`

## Rules
Decisions require traceable evidence, explicit authority and reproducible rationale. High-impact decisions require escalation and review.
