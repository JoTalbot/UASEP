# Automated Architecture Report

## Purpose
Generate a unified view of UASEP system readiness.

## Report Inputs

- Repository structure
- State artifacts
- Decision records
- Lessons learned
- Validation results
- Evidence records

## Report Sections

### Architecture Status
- protocol integrity
- component boundaries
- extension readiness

### Agent Readiness
- context availability
- ownership state
- task contract

### Evidence Status
- verified claims
- unknown states
- missing artifacts

### Risk Summary
- blockers
- regressions
- unresolved decisions

## Status Model

READY
BLOCKED
UNKNOWN

## Rule
A report must separate verified facts from assumptions.
