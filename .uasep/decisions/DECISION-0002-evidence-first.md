# DECISION-0002 — Evidence-first changes

## Context
Agent work requires reproducible verification.

## Decision
Every substantive change must be supported by verification evidence before completion is claimed.

## Alternatives
- Trusting agent self-reports only.
- Allowing unverified completion states.

## Evidence
- AGENTS.md task completion rules.
- Existing conformance approach.

## Impact
Improves traceability, recovery, and multi-agent collaboration.

## Status
Accepted
